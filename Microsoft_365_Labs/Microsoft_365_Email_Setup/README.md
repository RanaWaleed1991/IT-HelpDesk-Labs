# Outlook Setup & Mail Flow Test — Microsoft 365

**[View Full Lab Documentation](Microsoft_365_Email_Setup.md)**

## Purpose
This lab deploys the Microsoft 365 apps to a new Windows 10 workstation, connects desktop Outlook to an Exchange Online mailbox, and proves email works with a round-trip test to and from an external address.

---

## Scenario
A user's new PC has no Office apps, so they cannot use Outlook. The apps are installed from their Microsoft 365 Business Standard licence, Outlook is connected, and mail flow is verified in both directions before the ticket is closed.

---

## Prerequisites
- VMware Workstation Pro with a Windows 10 virtual machine
- A Microsoft 365 Business Standard (trial) account
- An external mailbox for testing (e.g. Gmail)

---

## Lab Tasks
1. **Confirm the workstation** is ready and has no Office apps.
2. **Install the Microsoft 365 apps** from the user's licence.
3. **Connect Outlook** to the Exchange Online mailbox.
4. **Send a test email** to an external address.
5. **Receive a reply** from the external address.

## Learning Outcomes
- Deploying Microsoft 365 apps and connecting Outlook via Autodiscover.
- Closing email tickets on an external round-trip test, not on "it opens".
- Using Outlook's connection status to separate client and connection problems.
