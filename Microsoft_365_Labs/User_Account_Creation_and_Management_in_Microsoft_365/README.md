# Sales New Starter — Microsoft 365 Onboarding

**[View Full Lab Documentation](M365_User_Creation_and_Verification.md)**

## Purpose
This lab onboards a new Sales team member in Microsoft 365: a licensed account, MFA enabled, membership of the Sales team in Microsoft Teams and a scoped admin role — then verifies email and Teams by signing in as the user.

---

## Scenario
A new starter is joining Sales and will also look after the team's Teams setup. Their account must be licensed, protected with MFA, added to the Sales team, and given only the admin access requested — and it must be proven to work before day one.

---

## Prerequisites
- Microsoft 365 tenant with Business Standard licences
- Global Administrator (or User Administrator) account
- Microsoft Teams and Outlook on the web
- A second browser session to sign in as the new user

---

## Lab Tasks
1. **Create and license** the user account.
2. **Enable MFA** for the user.
3. **Add the user to the Sales team** in Microsoft Teams.
4. **Assign the Teams Administrator role**, with a least-privilege review.
5. **Verify email** by signing in to Outlook as the user.
6. **Verify Teams** by opening the Sales channel as the user.
7. **Review the final account** in the Admin Center.

## Learning Outcomes
- End-to-end Microsoft 365 user onboarding.
- MFA enabled before first sign-in, and how per-user MFA relates to Conditional Access.
- Scoping admin roles and challenging over-broad access requests.
- Verifying onboarding from the user's side.
