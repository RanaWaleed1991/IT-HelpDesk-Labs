## How Each Lab Is Written

Every lab is documented as a **support ticket**, the way work arrives at a real service desk:

- **Ticket header** — subject, category, priority and the exact environment used
- **Problem Statement** — what the user or business reported, and what "done" looks like
- **Technical Steps** — diagnosis, fix and verification, each backed by a screenshot
- **Root cause / verification summary** — the evidence that the ticket is actually resolved
- **Key Takeaways** — the reasoning behind the steps, including what I would do differently in production

> **About the environments:** these labs were performed in my own home lab (VMware Workstation VMs, Microsoft 365 trial tenants, a ServiceNow developer instance) and, for the Group Policy lab, TryHackMe's Active Directory environment. The ticket scenarios are realistic framings of that hands-on work; where a fault was deliberately injected to reproduce a ticket, the lab says so. The PC performance lab was carried out on a real laptop.
